# Project Abstract

THUNAI – Senior Companion is a voice-first AI companion prototype designed to make everyday technology more approachable for older adults, especially those who prefer conversational interaction over complex menus. The project aims to combine Tamil, English and Tanglish communication with simple navigation, useful reminders, family connectivity, relaxation features and an accessible emergency-support interface. By bringing common tasks into one interface, THUNAI explores how conversational AI can support independence and companionship while preserving user choice and privacy.
