# Problem and Solution

## Problem statement
Some older adults find apps difficult to navigate because of small controls, complicated menus, language barriers and the need to switch between separate tools for routine tasks.

## Proposed solution
A voice-first, accessible companion with readable screens, Tamil/English/Tanglish interaction, reminders, user-approved preferences, trusted family contact access and a prominent user-initiated SOS control.

## Intended impact
- Reduce friction for common digital tasks.
- Support accessible, multilingual interaction.
- Help users manage reminders and reach trusted contacts.
- Encourage independent use without replacing human support.

## Boundaries
Not a medical diagnostic system, a guaranteed crisis detector or an emergency response provider.
